# Smart Study Planner

## Problem Statement
Smart Study Planner is a web application that helps students organize their subjects, exam dates, and available study hours.

## Solution
The application generates a day-by-day study timetable based on the student's inputs. It also provides a progress checklist to help students track completed study tasks.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Enter subjects
- Enter exam dates
- Enter available study hours
- Generate a day-by-day study plan
- Track progress using checkboxes

## How to Run
1. Open the Smart Study Planner project folder in Visual Studio Code.
2. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
3. Open `index.html` in Google Chrome.
4. Enter the subjects, exam dates, and available study hours.
5. Click **Generate Study Plan**.
6. Use the checkboxes to track progress.
